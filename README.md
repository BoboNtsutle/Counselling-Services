Project Description
The Counseling Services Appointment Manager is a centralized system developed to modernize and streamline the psychological counseling operations for the Wellness Centre at the Central University of Technology, Free State. The system replaces legacy paper records and Outlook-based appointment flows with a cross-platform solution comprising a Flutter mobile application and an ASP.NET Core web application connected to a shared Supabase (PostgreSQL) backend.
Brief Explanation of the Stakeholder Problem .
The Wellness Centre currently relies on manual paper processes, Excel spreadsheets, and Outlook calendar bookings. This fragmented workflow leads to significant operational challenges:  
Missed Requests & Double Bookings: Booking emails sent via Outlook are easily overlooked, and the absence of automated schedule checks causes frequent overlapping appointments. 
Misplaced Records & Lack of Searchability: Physical student records are occasionally lost, with no system in place to quickly search or retrieve client history. 
Administrative Burden: Psychologists struggle to manually track and compile statistical reports while conducting back-to-back sessions. 
Resource Misalignment: Students occasionally arrive for sessions when no psychologist is available to attend to them. 

Technologies
Mobile Frontend: Flutter 
Web Frontend & Backend API: ASP.NET Core  
Database & Cloud Backend: Supabase (PostgreSQL)
